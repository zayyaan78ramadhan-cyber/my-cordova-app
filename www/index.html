           Panduan Penggunaan
        

        
      

      

        
1. Pindai Otomatis: Unggah foto struk, lalu potong area layar jika diperlukan. Klik "Pindai & Isikan Angka Otomatis".

        
2. Header Laporan: Masukkan Nama Halte dan Jam Data di bagian paling atas.

        
3. Gate Tanpa Batas: Jumlah gate tidak dibatasi. Gate baru akan otomatis muncul ketika Anda berpindah ke gate berikutnya.

        
4. Navigasi Cepat (Enter): Tekan tombol Enter pada HP/PC untuk otomatis berpindah ke kotak input berikutnya.

        
5. Kirim Pesan: Tekan "Kirim Ke WA" atau "Salin Teks" untuk mengambil format rekap otomatis.
